1

Install Laravel

One command installs PHP, Composer, and the Laravel installer on any platform.

# macOS

/bin/bash -c "$(curl -fsSL https://php.new/install/mac)"

# Windows

Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://php.new/install/windows'))

# Linux

/bin/bash -c "$(curl -fsSL https://php.new/install/linux)"

Already have PHP? Skip ahead — just make sure you have Composer installed.

2

Create your app

The Laravel installer asks a few questions and scaffolds everything — auth, database, testing framework.

laravel new my-app

You now have a working app with login, registration, password reset, and a database — ready to build on.

3

Supercharge with Boost

Install Laravel Boost to give your AI agent deep knowledge of Laravel conventions, best practices, and your project structure.

composer require laravel/boost --dev

php artisan boost:install

Boost sets up an MCP server, AI guidelines, and agent skills. Claude Code, Cursor, and Codex will now write better Laravel code — automatically.

4

Build with AI

Open Claude Code in your project directory and start describing features. Here's how you'd build a real household management app — prompt by prompt.

~ $ claude

Prompt 1 — Data model

I'm building a household management app called Dwellsmith. Create the core data model:

- Households (name, address, timezone) — users belong to a household

- Rooms (name, household_id) — spaces within the home

- Items (name, room_id, category, purchase_date, notes) — things in each room

- Chores (name, frequency, assigned_to, last_completed, next_due)

Use Eloquent relationships. Add factories and seeders with realistic data.

✓ 4 migrations, 4 models with relationships

✓ Updated User model with household belongsTo

✓ Seeders: 2 households, 8 rooms, 30 items, 12 chores

Prompt 2 — Dashboard & navigation

Build the main dashboard. After login, users see:

- Their household name + member count

- Chores due today and this week (with "mark done" buttons)

- Room-by-room item count summary

- Sidebar nav: Dashboard, Rooms, Items, Chores, Settings

Scope everything to the logged-in user's household.

✓ DashboardController with household-scoped queries

✓ App layout with sidebar navigation

✓ Chore completion via POST with date tracking

Prompt 3 — Full CRUD

Add full CRUD for Rooms and Items. Each room page shows its items.

- Rooms: create, edit, delete (with confirmation)

- Items: create, edit, move between rooms, delete

- Items should be filterable by category and searchable by name

- Use Form Requests for validation

- Add authorization — users can only manage their own household's data

✓ RoomController + ItemController (resourceful routes)

✓ StoreRoomRequest, UpdateItemRequest with auth

✓ Policy classes scoping all actions to household

Prompt 4 — Chore scheduling & notifications

Make chores smart:

- Support frequencies: daily, weekly, biweekly, monthly

- Auto-calculate next_due when marked complete

- Add an artisan command that sends email reminders for chores due today

- Schedule it to run daily at 8am via Laravel's scheduler

- Show overdue chores in red on the dashboard

✓ Chore frequency enum + next_due calculation

✓ SendChoreReminders command + Mailable

✓ Scheduled in console.php, overdue styling in dashboard

Prompt 5 — Household invites

Add the ability to invite people to your household:

- Settings page with "Invite Member" form (email)

- Generate a signed URL invite link (expires in 7 days)

- Send invite via email with the link

- Clicking the link registers (or logs in) and joins the household

✓ Invite model + migration with signed URL token

✓ HouseholdInviteMail with accept link

✓ InviteController with accept flow + existing user handling

💡

That's a real app. Five prompts got you a multi-user household manager with rooms, items, chores, scheduling, email notifications, and invite links. Each prompt builds on the last because Laravel's conventions mean the AI always knows where things are.

With Boost installed, your AI agent queries the Laravel documentation MCP server for the latest APIs — no hallucinating outdated syntax.

5

Test locally

Make sure everything works before deploying.

php artisan serve

INFO Server running on [http://127.0.0.1:8000]

Open localhost:8000 in your browser. Login works. Your features work. You're ready to ship.

6

Deploy to Laravel Cloud

Push your code to GitHub, connect it to Laravel Cloud, and deploy. That's it.

Push to GitHub

git init && git add -A && git commit -m "Initial commit"

gh repo create my-app --public --source=. --push

Create your Cloud application

  1. a Go to cloud.laravel.com and click + New Application
  2. b Connect GitHub — authorize Laravel Cloud to access your repositories
  3. c Select your repo, name your app, and choose a region
  4. d Click Create Application — your environment is provisioned automatically
  5. e Add any environment variables or a database from the infrastructure canvas, then hit Deploy
🚀

You're live.

Your app is deployed with SSL, CDN, and auto-scaling. Push to your main branch and Cloud redeploys automatically.
